你需要确保的后端服务
你的 simpleflow.finance 后端需要提供以下服务：

thegraph.simpleflow.finance - Graph API 代理
profile.simpleflow.finance - Profile API
nft.simpleflow.finance - NFT API
farms-api.simpleflow.finance - Farms API
wallet-api.simpleflow.finance - Wallet API
tokens.simpleflow.finance - Token lists
assets.simpleflow.finance - 静态资源 CDN
configs.simpleflow.finance - 配置 API
现在所有网络请求都会发送到你自己的 simpleflow.finance 域名，PancakeSwap 无法追踪你的活动。
